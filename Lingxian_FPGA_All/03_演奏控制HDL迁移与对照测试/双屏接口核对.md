# 双屏直连FPGA：真实迁移前的接口核对

目前已交付的Tang37／野火38并不是FPGA直接驱动两屏。Tang自带控制屏直接连接FPGA；第二块3.2寸演奏屏通过外部控制器的16位并口显示，触摸通过XPT2046采集，WiFi通过USART3连接。此次目标是将这些控制状态机真实改为HDL，而不是只改命名。

## 现有第二屏接口（依据当前固件）

屏幕逻辑分辨率320×240，物理240×320。当前固件支持ILI9341／ST7789V控制器，并有读ID和不同初始化分支，因此需确认实际模块型号。

### 显示：8080型16位并口

| 屏幕功能 | 当前连接／映射 |
|---|---|
| D0、D1、D2、D3 | PD14、PD15、PD0、PD1 |
| D4～D12 | PE7～PE15 |
| D13、D14、D15 | PD8、PD9、PD10 |
| CS（NE1） | PD7 |
| RD（NOE） | PD4 |
| WR（NWE） | PD5 |
| RS／DC（A16） | PD11 |
| RESET | PE1 |
| 背光控制 | PD12，现有固件低电平点亮 |

以上是原控制器的端口名称，不是新FPGA接点，也不代表模块连接器针号。具体屏端针号需看屏幕连接器／转接板标识或原理图。

### 触摸：XPT2046

| 功能 | 当前连接 |
|---|---|
| CS | PD13 |
| CLK | PE0 |
| MOSI | PE2 |
| MISO | PE3 |
| PENIRQ | PE4 |

这块屏的触摸不是Tang控制屏的FT6x36 I²C触摸，不能直接复用原来的四根CTP接线。

## 目标HDL分工

1. 8080总线控制器：显示命令/数据读写、总线三态、时序、复位、屏幕初始化。
2. 演奏页绘图器：钢琴/吉他/风琴/鼓组与触摸高亮，复用既有字形和逐像素渲染思路。
3. XPT2046采集与坐标校准：多次采样、去极值、坐标变换、掉点保护。
4. 演奏控制器：键位映射、滑键稳定、和弦、增益、触发和松手，直接连接FPGA现有live_keys/live_gain路径。
5. WiFi AT状态机与二进制协议：启动/兼容命令、+IPD解帧、回复发送、CRC、曲谱和键位配置。
6. 非易失存储：原外部控制器Flash中的双页日志不能简单改成FPGA RAM；如保留断电保存，需要另选板载Flash/SD等真实存储并实现控制器与原子更新。

原32声部合成、混音、效果、四轨循环和旋钮逻辑可作为迁移基线保留。当前工程DSP资源已映射118/118，新增控制逻辑需要尽量使用状态机、逻辑和存储，并重新完成布局布线检查。

## 继续前需要确认的实物信息

- 第二屏背面型号、连接器丝印及屏与载板连接方式。
- 原理图或可看清针号的连接器近照，以确认上述总线是否能引出。
- WiFi模块型号、TX/RX/EN引出点，和是否允许重新接线。
- 供电与原控制器停止驱动方案。没有确认隔离/复位状态前，不把FPGA输出并接到原控制器仍可能驱动的总线上。

在这些条件确认前，本清单不是可直接上板的接线图，也没有生成新的可烧录迁移固件。
